## Local delivery

`action.yml` runs `dist/index.mjs` on Node 24. `npm run build` bundles the source and locked dependencies with esbuild; no npm install is required by an action consumer. Commit the bundle with its source. `npm run build:check` compares an in-memory rebuild to the shipped file and fails on drift. The bundle keeps dependency license comments.

CI runs lint, typecheck, bundle consistency and unit/integration tests on every push and PR, with read-only repository permissions and no model keys. Bundle tests copy the file to a temporary directory outside the repo, replace fetch with an offline stub and execute a child Node process without inherited credentials.
